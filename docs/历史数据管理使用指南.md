# 历史数据管理使用指南

## 概述

本系统提供了完整的历史数据管理功能，支持多种资产类型、多个数据源、多种周期和多种数据格式。系统基于TET（Transform-Extract-Transform）数据管道架构，提供高效、可靠的数据访问。

## 核心组件

### 1. UnifiedDataManager（统一数据管理器）

**主要功能：**
- 协调数据加载请求
- 避免重复数据加载
- 提供统一的数据访问接口
- 管理数据缓存
- 优化数据加载性能
- 支持TET数据管道
- 多资产类型数据处理
- 集成多数据源
- 行业数据管理
- SQLite和DuckDB数据库支持

**支持的资产类型：**
- 股票（A股、港股、美股）
- 指数
- 基金
- 债券
- 加密货币
- 期货

**支持的数据源：**
- 东方财富
- 新浪财经
- 同花顺
- TDX（通达信）
- FactorWeave-Quant
- 自定义插件

### 2. 专门的数据管理器

#### SmartDataManager
- 智能数据复制策略
- LRU缓存机制
- 内存优化

#### EnhancedRealtimeDataManager
- Level-2行情数据
- Tick数据
- 订单簿数据
- 实时数据订阅

#### FundamentalDataManager
- 财务报表数据
- 公司公告
- 分析师评级
- 基本面指标

#### MacroEconomicDataManager
- 宏观经济指标
- 行业数据
- 市场数据

## 基本使用

### 1. 初始化数据管理器

```python

from core.containers import get_service_container
from core.events.event_bus import EventBus

# 创建事件总线
```

## 数据质量控制

### 1. 数据完整性检查

```python
# 检查数据完整性
def check_data_completeness(df):
    missing_values = df.isnull().sum()
    print("缺失值统计:")
    print(missing_values)
    
    # 检查日期连续性
    if 'datetime' in df.columns:
        date_range = pd.date_range(
            start=df['datetime'].min(),
            end=df['datetime'].max(),
            freq='D'
        )
        missing_dates = set(date_range) - set(df['datetime'])
        print(f"缺失日期: {len(missing_dates)}天")

check_data_completeness(df)
```

### 2. 数据异常检测

```python
# 检测异常数据
def detect_anomalies(df):
    # 价格异常检测
    price_cols = ['open', 'high', 'low', 'close']
    for col in price_cols:
        if col in df.columns:
            # 检查负值
            if (df[col] < 0).any():
                print(f"{col}列存在负值")
            
            # 检查极端值（超过3倍标准差）
            mean = df[col].mean()
            std = df[col].std()
            outliers = df[(df[col] < mean - 3*std) | (df[col] > mean + 3*std)]
            if len(outliers) > 0:
                print(f"{col}列存在{len(outliers)}个异常值")
    
    # 成交量异常检测
    if 'volume' in df.columns:
        # 检查零成交量
        zero_volume = (df['volume'] == 0).sum()
        print(f"零成交量天数: {zero_volume}天")

detect_anomalies(df)
```

### 3. 数据清洗

```python
# 清洗数据
def clean_data(df):
    # 去除重复数据
    df = df.drop_duplicates()
    
    # 填充缺失值
    df = df.fillna(method='ffill')  # 前向填充
    df = df.fillna(method='bfill')  # 后向填充
    
    # 去除异常值
    price_cols = ['open', 'high', 'low', 'close']
    for col in price_cols:
        if col in df.columns:
            mean = df[col].mean()
            std = df[col].std()
            df[col] = df[col].clip(lower=mean - 3*std, upper=mean + 3*std)
    
    return df

cleaned_df = clean_data(df)
```

```python
import asyncio

# 并行获取多只股票数据
async def parallel_query(symbols):
    tasks = []
    for symbol in symbols:
        task = asyncio.create_task(
            data_manager.get_kdata_async(
                stock_code=symbol,
                period='D',
                start_date='2023-01-01',
                end_date='2023-12-31'
            )
        )
        tasks.append(task)
    
    results = await asyncio.gather(*tasks)
    return results

results = await parallel_query(symbols)
```

## 常见问题

### 1. 数据获取失败

**问题**：获取数据时返回空DataFrame

**解决方法**：
- 检查股票代码是否正确
- 检查时间范围是否合理
- 检查网络连接
- 尝试更换数据源

### 2. 数据不完整

**问题**：数据存在缺失值或日期不连续

**解决方法**：
- 使用数据清洗功能
- 填充缺失值
- 检查数据源质量
- 使用多个数据源交叉验证

### 3. 性能问题

**问题**：数据获取速度慢

**解决方法**：
- 启用缓存
- 使用批量查询
- 使用并行操作
- 优化数据库查询

### 4. 内存问题

**问题**：处理大量数据时内存不足

**解决方法**：
- 分批处理数据
- 使用数据库存储
- 释放不再使用的数据
- 使用数据压缩
