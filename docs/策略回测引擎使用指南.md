# 策略回测引擎使用指南

## 概述

本系统提供了专业级的策略回测引擎，支持多种回测模式、优化级别和风险管理策略。系统对标专业量化软件，提供高性能、高可靠性的回测功能。

## 核心引擎

### 1. UnifiedBacktestEngine（统一回测引擎）

**主要功能：**
- 整合所有回测功能
- 自动选择最优引擎
- 支持多种回测级别
- 支持多种风险管理级别
- 对标专业量化软件

**回测级别：**
- BASIC - 基础回测
- STANDARD - 标准回测
- PROFESSIONAL - 专业回测
- ULTRA - 超级回测

**风险管理级别：**
- BASIC - 基础风险管理
- STANDARD - 标准风险管理
- PROFESSIONAL - 专业风险管理
- ULTRA - 超级风险管理

### 2. VectorizedBacktestEngine（向量化回测引擎）

**主要功能：**
- 使用NumPy向量化操作
- Numba JIT编译
- 3-5倍性能提升
- 支持并行计算
- 支持快速数学运算

**优化级别：**
- BASIC - 基础优化
- STANDARD - 标准优化
- PROFESSIONAL - 专业优化（启用所有优化）

### 3. ParallelBacktestEngine（并行回测引擎）

**主要功能：**
- 支持多策略并行回测
- 支持多参数并行回测
- 支持多股票并行回测
- 支持多进程/多线程
- 自动负载均衡

**执行模式：**
- 多进程模式（CPU密集型）
- 多线程模式（I/O密集型）

### 4. MemoryOptimizedBacktestEngine（内存优化回测引擎）

**主要功能：**
- 针对大数据集优化
- 分块处理数据
- 智能内存管理
- 自动垃圾回收
- 内存使用监控

**优化特性：**
- 分块处理（可配置块大小）
- 智能数据复制
- 资源自动管理
- 内存使用监控

### 5. PortfolioBacktestEngine（投资组合回测引擎）

**主要功能：**
- 支持多资产投资组合
- 支持资产配置优化
- 支持相关性分析
- 支持风险分散

### 3. 定义交易策略

```python
import numpy as np
import pandas as pd

def simple_ma_strategy(data, short_window=5, long_window=20):
    """
    简单双均线策略
    
    Args:
        data: 历史数据
        short_window: 短期均线窗口
        long_window: 长期均线窗口
    
    Returns:
        DataFrame: 包含信号的数据
    """
    # 计算均线
    data['ma_short'] = data['close'].rolling(window=short_window).mean()
    data['ma_long'] = data['close'].rolling(window=long_window).mean()
    
    # 生成交易信号
    data['signal'] = 0
    data.loc[data['ma_short'] > data['ma_long'], 'signal'] = 1   # 买入信号
    data.loc[data['ma_short'] < data['ma_long'], 'signal'] = -1  # 卖出信号
    
    return data
```

## 风险管理

### 1. 止损策略

```python
def strategy_with_stop_loss(data, stop_loss_pct=0.05):
    """
    带止损的策略
    
    Args:
        data: 历史数据
        stop_loss_pct: 止损百分比（5%）
    
    Returns:
        DataFrame: 包含信号的数据
    """
    # 应用基础策略
    data = simple_ma_strategy(data)
    
    # 计算止损价格
    data['stop_loss_price'] = data['close'] * (1 - stop_loss_pct)
    
    # 检查是否触发止损
    data['signal'] = 0
    for i in range(1, len(data)):
        if data.loc[i-1, 'signal'] == 1:  # 如果前一天是买入信号
            if data.loc[i, 'close'] < data.loc[i-1, 'stop_loss_price']:  # 触发止损
                data.loc[i, 'signal'] = -1  # 卖出
            else:
                data.loc[i, 'signal'] = data.loc[i-1, 'signal']  # 保持持仓
    
    return data
```

def strategy_with_take_profit(data, take_profit_pct=0.10):
    """
    带止盈的策略
    
    Args:

### 3. 仓位管理

```python
def strategy_with_position_sizing(data, position_sizing_method='fixed', max_position_pct=0.2):
    """
    带仓位管理的策略
    
    Args:
        data: 历史数据
        position_sizing_method: 仓位管理方法
        max_position_pct: 最大仓位百分比
    
    Returns:
        DataFrame: 包含信号和仓位的数据
    """
    # 应用基础策略
    data = simple_ma_strategy(data)
    
    # 计算仓位大小
    if position_sizing_method == 'fixed':
        data['position_size'] = max_position_pct
    elif position_sizing_method == 'volatility':
        # 基于波动率的仓位管理
        data['volatility'] = data['close'].pct_change().rolling(20).std()
        data['position_size'] = max_position_pct / data['volatility']
        data['position_size'] = data['position_size'].clip(0, max_position_pct)
    elif position_sizing_method == 'kelly':
        # 凯利公式
        win_rate = 0.55  # 假设胜率55%
        avg_win = 0.10  # 平均盈利10%
        avg_loss = 0.05  # 平均亏损5%
        kelly_pct = (win_rate * avg_win - (1 - win_rate) * avg_loss) / avg_win
        data['position_size'] = min(kelly_pct, max_position_pct)
    
    return data
```

## 性能分析

### 1. 性能指标计算

```python
def calculate_performance_metrics(result):
    """
    计算性能指标
    
    Args:
        result: 回测结果
    
    Returns:
        Dict: 性能指标字典
    """
    metrics = {}
    
    # 基本指标
    metrics['total_return'] = (result['capital'].iloc[-1] / result['capital'].iloc[0] - 1) * 100
    metrics['annual_return'] = metrics['total_return'] / 3  # 假设3年数据
    
    # 回撤指标
    cummax = result['capital'].cummax()
    drawdown = (cummax - result['capital']) / cummax * 100
    metrics['max_drawdown'] = drawdown.max()
    metrics['avg_drawdown'] = drawdown.mean()
    
    # 收益率指标
    returns = result['returns'].dropna()
    metrics['annual_volatility'] = returns.std() * np.sqrt(252) * 100
    metrics['sharpe_ratio'] = (returns.mean() * 252 - 0.03) / (returns.std() * np.sqrt(252))
    
    # 交易指标
    trades = result[result['signal'] != 0]
    metrics['total_trades'] = len(trades)
    metrics['win_rate'] = (trades['returns'] > 0).sum() / len(trades) * 100
    
    # 盈亏比
    win_trades = trades[trades['returns'] > 0]
    loss_trades = trades[trades['returns'] < 0]
    if len(win_trades) > 0 and len(loss_trades) > 0:
        metrics['avg_win'] = win_trades['returns'].mean() * 100
        metrics['avg_loss'] = loss_trades['returns'].mean() * 100
        metrics['profit_loss_ratio'] = abs(metrics['avg_win'] / metrics['avg_loss'])
    
    return metrics

# 计算性能指标
metrics = calculate_performance_metrics(result)

# 打印性能指标
print("=== 性能指标 ===")
for key, value in metrics.items():
    print(f"{key}: {value:.2f}")
```

## 常见问题

### 1. 回测速度慢

**问题**：回测运行时间过长

**解决方法**：
- 使用向量化引擎
- 使用并行回测
- 减少数据量
- 优化策略逻辑
- 使用更快的硬件

### 2. 内存不足

**问题**：处理大数据集时内存不足

**解决方法**：
- 使用内存优化引擎
- 分块处理数据
- 减少数据量
- 释放不再使用的数据
- 使用64位Python

### 3. 过拟合

**问题**：回测结果很好，但实盘表现差

**解决方法**：
- 使用交叉验证
- 增加样本外测试
- 减少参数数量
- 使用更长的历史数据
- 考虑交易成本

### 4. 策略失效

**问题**：策略在实盘中失效

**解决方法**：
- 定期重新优化参数
- 考虑市场环境变化
- 增加风险管理
- 使用多个策略组合
- 监控策略表现
